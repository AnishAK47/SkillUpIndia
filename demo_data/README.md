Demo assets folder. The built-in demand and curriculum data lives in `data/`.

- `sample_job_postings.csv`: 10 fictional data-role postings (sample companies, Indian cities). Upload it in **Data ingestion → CSV dataset upload** to rebuild the demand baseline.

For a live demo you can also:
- **Data ingestion:** paste any job description instead of uploading the CSV.
- **Resume to profile** and **Curriculum upload:** upload any text-based resume or syllabus PDF.
